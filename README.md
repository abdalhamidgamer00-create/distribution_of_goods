# نظام توزيع البضائع - صيدليات محروس 💊

نظام شامل لإدارة توزيع البضائع، المشتريات، والتحويلات بين فروع صيدليات محروس.

## 🌟 المميزات

- **إدارة المشتريات**: رفع ملفات Excel، تحليل البيانات، وإنشاء تقارير النواقص والفائض.
- **سياسة مخزون ديناميكية**: إمكانية تخصيص أيام التغطية لكل من (الاحتياج، الفائض، والنقص) بشكل لحظي.
- **توزيع البضائع**: خوارزميات ذكية لتوزيع البضائع بين الفروع (الإدارة، العشرين، الورداني، العقبي، الشهيد، النجوم).
- **واجهة رسومية**: واجهة سهلة الاستخدام مبنية بواسطة Streamlit مع أشرطة تمرير (Sliders) للتحكم في السياسات.
- **أمان**: نظام تسجيل دخول لحماية البيانات.
- **تقارير**: تصدير تقارير Excel و CSV منظمة.

## 🚀 طريقة التشغيل

1. **تثبيت المتطلبات**:
   ```bash
   pip install -r requirements.txt
   ```

2. **تشغيل الواجهة الرسومية**:
   ```bash
   streamlit run src/presentation/gui/app.py
   ```

3. **التشغيل عبر سطر الأوامر (CLI)**:
   يمكنك تشغيل النظام بالكامل مع تحديد أيام التغطية:
   ```bash
   python main.py --all --latest --need 20 --surplus 60 --shortage 30
   ```
   *المعاملات المتاحة:*
   - `--all`: تشغيل كافة خطوات النظام.
   - `--need`: أيام تغطية الاحتياج (الافتراضي: 20).
   - `--surplus`: أيام تغطية الفائض (الافتراضي: 60).
   - `--shortage`: أيام تغطية النقص (الافتراضي: 30).

3. **تسجيل الدخول**:
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`

## 📂 هيكل المشروع

- `src/`: الكود المصدري
  - `presentation/gui/`: واجهة المستخدم (Streamlit)
  - `application/pipeline/`: منطق المعالجة والأدوات
  - `domain/`: منطق الأعمال والقواعد الأساسية
- `data/`: مجلد البيانات (يتم تجاهله في Git للحفاظ على الخصوصية)
